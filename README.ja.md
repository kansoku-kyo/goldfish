# Goldfish

English: [README.md](README.md)

ブラウザで動くトレーディングカードゲームのソロプレイテスト用アプリです。
ドロー、山札をきる、フィールドにカードを出す、手札・山札・トラッシュの管理ができ、
配信用の観戦ビューも表示できます。

## デッキを用意する

デッキはカード画像を入れたフォルダです。異なるカードごとに1枚の画像を用意し、
ファイル名は `<カード名> xN.png`（`.jpg`、`.jpeg`、`.webp`、`.svg` も可）で、`N` は
デッキ内の枚数です（例：`Dragon x4.png`）。1枚だけの場合は ` xN` を省略できます。
同じフォルダに `cardback.png` を置くと、そのデッキの裏面として使われます。

☰ → **ディスクから読み込む…** で、PC上のデッキフォルダを選びます。

### サンプルデッキ

デッキがまだない場合は、標準的な54枚のトランプデッキを生成できます
（アプリが描画するもので、著作権のある絵柄は使いません）：

```
python tools/make_poker_deck.py --out <デッキフォルダ>
```

できた `Poker` フォルダを **ディスクから読み込む…** で取り込みます。ローカルで
実行している場合は `--out` を省くと `decks/` に直接作られます。

### デッキの保存場所

- **Chrome / Edge**：PC上のフォルダを選びます（☰ → デッキフォルダ → 選択…）。
  デッキはそのフォルダから読み込まれ、そこへ取り込まれます。リロード後は
  ブラウザが再び読めるよう、**再接続** を一度クリックしてください。
- **Firefox / Safari**：デッキはブラウザ内の IndexedDB という保存領域に
  入ります。リロードしても残りますが、そのブラウザプロファイル内だけに存在し、
  サイトデータの削除や ☰ → **アプリのデータを初期化…** で消えます。

## あなたのデータ

アプリが記憶する内容はすべてあなたのPC内にあります。進行中のゲームと設定は
ブラウザのローカルストレージに、デッキは選んだフォルダまたは IndexedDB に
保存されます。外部には何も送信しません。

すべて消すには ☰ → **アプリのデータを初期化…** を使ってください。保存された
ゲーム、設定、ブラウザ内に保存されたデッキが削除され、選択していたデッキ
フォルダの記憶も消えます。そのフォルダ内のファイル自体は残ります。

## 遊び方

- **☰メニュー**：デッキ選択、新しいゲーム（やり直しにも使用）、読み込み、
  配信ウィンドウ、ログ、言語、初期化。
- **フィールド**：カードを自由に置けます。ダブルクリックでActive/Standby切替、
  右クリックでカードメニュー。空いている場所をドラッグすると複数選択でき、
  まとめて動かせます。フィールドメニューから全カードをActiveに、または全て
  手札・トラッシュへ移動できます。
- **グループ**：カードを選択して `Ctrl+G` でグループ化。グループは一体で動き、
  重なり順を保ちます。Active/Standbyは1枚ずつです。`Ctrl+Shift+G` で解除。
- **入れ替え**：2枚のカードまたはグループを選んで `X`、または `Alt` を押しながら
  カードを別のカードにドロップすると位置を入れ替えます。
- **手札**：ドラッグで並べ替えできます。メニューから全カードを山札の上／下へ
  （順番通り、またはランダム）、トラッシュへ、または1枚ランダムに捨てます。
- **山札・トラッシュ**：山札をクリックでドロー、トラッシュをクリックで中身を表示。
  メニューにはドロー、一番上を表向き／裏向きで出す、山札を見る／検索、
  トラッシュする、山札をきる、などがあります。山をフィールドにドラッグすると
  一番上のカードをその位置に置けます。山札から `Shift` を押しながらドラッグ
  すると裏向きで置きます。山札・トラッシュのビューア内のカードは、そのまま
  フィールド・手札・山札・トラッシュへドラッグできます。
- **カウンター**：上部バーには最初から「ライフ」というカウンターがあります。
  その横の ⚙ ボタンで名前や初期値、上限・下限を変更したり、追加したり
  できます。設定はブラウザに保存されます。

ショートカット：

- `D` ドロー、`S` 山札をきる、`N` 次のターン、`Ctrl+Z` 元に戻す、`Esc` 閉じる
- カーソルを合わせたカード：`B` フィールドへ、`T` Active/Standby、`F` 表裏、
  `R` 手札へ、`G` トラッシュへ、`L` 山札の上へ、`Shift+L` 山札の下へ
- 選択：`Shift`+クリックで追加／解除、`Ctrl+G` グループ化、
  `Ctrl+Shift+G` 解除、`X` 2つを入れ替え

## 配信

☰ → **配信ウィンドウを開く** で、配信で共有するための別ウィンドウが開きます。
手札と裏向きのカードは隠され、トラッシュビューアは同じ内容が映り、山札を見ている間は
通知だけが表示されます。

## 言語

☰ → **Language / 言語** で英語と日本語を切り替えます。初回はブラウザの言語に
合わせて選ばれます。

## PCで動かす場合

Webサイトを使わず自分のPCで動かすこともできます。必要なのは Python 3 だけです。

```
python server.py
```

`http://localhost:8000` が開きます。デッキはスクリプトと同じ場所の `decks/`
フォルダに置きます。

`config.json` で既定のカウンターと初期手札の枚数を設定できます。アプリ内で
編集したカウンターはそれを上書きします。
